最小二乘法

最小二乘法是用来做函数拟合的一种思想。

最小二乘

按照勒让德的最佳原则，求损失函数最小值：

min⁡L=∑i=1n(yi−f(x))2，yi观测数据，f(x)拟合模型\min L = \sum_{i=1}^n (y_i - f(x))^2， y_i\text{观测数据}， f(x)\text{拟合模型} minL=i=1∑n​(yi​−f(x))2，yi​观测数据，f(x)拟合模型

至于为什么平方（二乘）是最佳，高斯给出了答案（具体答案是什么我也不知道哈哈，没看）。

举几个例子对比一下：

E1=∑i=1n(yi−f(x))E2=∑i=1n∣yi−f(x)∣E3=∑i=1n(yi−f(x))2\begin{aligned} E_1 &= \sum_{i=1}^n (y_i - f(x)) \\ E_2 &= \sum_{i=1}^n |y_i - f(x)| \\ E_3 &= \sum_{i=1}^n (y_i - f(x))^2 \end{aligned} E1​E2​E3​​=i=1∑n​(yi​−f(x))=i=1∑n​∣yi​−f(x)∣=i=1∑n​(yi​−f(x))2​

E1E_1E1​显然是带符号的，又很强的“个性”， 正负值会互相抵消，但是有可能损失函数依旧很大，差评！
E2E_2E2​不带符号了，但它是绝对值函数，不可微，用不了微积分！
E3E_3E3​相比之下是个不错的选择。

举个栗子

以线性回归为例：

hθ(x1,x2,…,xn)=θ0+θ1x1+⋯+θnxn，θ是参数。h_\theta(x_1,x_2,\dots,x_n)=\theta_0 + \theta_1 x_1 + \cdots + \theta_n x_n，\theta\text{是参数。} hθ​(x1​,x2​,…,xn​)=θ0​+θ1​x1​+⋯+θn​xn​，θ是参数。

为了找到最好的hhh，我们疯狂取样mmm个

h1=θ0+θ1x1(1)+⋯+θnxn(1)⋮hm=θ0+θ1x1(m)+⋯+θnxn(m)\begin{aligned} h_1 &= \theta_0 + \theta_1 x^{(1)}_1 + \cdots + \theta_n x^{(1)}_n \\ &\vdots \\ h_m &= \theta_0 + \theta_1 x^{(m)}_1 + \cdots + \theta_n x^{(m)}_n \end{aligned} h1​hm​​=θ0​+θ1​x1(1)​+⋯+θn​xn(1)​⋮=θ0​+θ1​x1(m)​+⋯+θn​xn(m)​​

用矩阵表示（x0=1x_0 = 1x0​=1，为了凑矩阵）：

hm×1=Xm×(n+1)θ(n+1)×1\boldsymbol{h}_{m\times 1} = \boldsymbol{X}_{m\times(n+1)}\boldsymbol{\theta}_{(n+1)\times 1} hm×1​=Xm×(n+1)​θ(n+1)×1​

所以：L(θ)=∥h−Y∥2=∥Xθ−Y∥2=(Xθ−Y)T(Xθ−Y)L(\boldsymbol{\theta}) = \|\boldsymbol{h} - \boldsymbol{Y} \|^2 = \|\boldsymbol{X\theta} - \boldsymbol{Y}\|^2 = (\boldsymbol{X\theta} - \boldsymbol{Y})^T(\boldsymbol{X\theta} - \boldsymbol{Y})L(θ)=∥h−Y∥2=∥Xθ−Y∥2=(Xθ−Y)T(Xθ−Y)，Y\boldsymbol{Y}Y是m×1m\times 1m×1的输出向量。

一点矩阵微积分的东西：

∂XTa∂x=∂aTX∂X=a,∂XTAx∂x=Ax+ATx\frac {\partial\boldsymbol{X}^T\boldsymbol{a}} {\partial x} = \frac {\partial\boldsymbol{a}^T\boldsymbol{X}} {\partial \boldsymbol{X}} = a, \frac {\partial\boldsymbol{X}^T\boldsymbol{A}x} {\partial x} = \boldsymbol{A}x + \boldsymbol{A}^T x ∂x∂XTa​=∂X∂aTX​=a,∂x∂XTAx​=Ax+ATx

化简：

L(θ)=θTXTXθ−θTXTY−YTXθ+YTYL(\boldsymbol{\theta}) = \boldsymbol{\theta}^T\boldsymbol{X}^T\boldsymbol{X\theta} - \boldsymbol{\theta}^T\boldsymbol{X}^T\boldsymbol{Y} - \boldsymbol{Y}^T\boldsymbol{X\theta} + \boldsymbol{Y}^T\boldsymbol{Y} L(θ)=θTXTXθ−θTXTY−YTXθ+YTY

为了找到L(θ)L(\boldsymbol{\theta})L(θ)的最小值，使它的导数等于0.

∂∂θL(θ)=2XTXθ−2XTY=0\frac{\partial}{\partial\boldsymbol{\theta}}L(\boldsymbol{\theta}) = 2\boldsymbol{X}^T\boldsymbol{X}\boldsymbol{\theta} - 2\boldsymbol{X}^T\boldsymbol{Y} = 0 ∂θ∂​L(θ)=2XTXθ−2XTY=0

所以θ=(XTX)−1XTY\boldsymbol{\theta} = (\boldsymbol{X}^T\boldsymbol{X})^{-1}\boldsymbol{X}^T\boldsymbol{Y}θ=(XTX)−1XTY。这也叫正规方程（Normal Equation）。
